## 2. Load-time: accept a default on datetime, refuse a bare token in one

- [x] 2.1 In `TryFrom<RawParamSpec>` (`src/convert.rs`), collapse an explicit YAML null `default:` to `None` for **every** type *before* any type-specific check runs.
- [x] 2.2 Stop rejecting `default:` on a `datetime` parameter and carry it through into `ParamSpec`. Keep rejecting `format`, `min`, `max`, `multiline`, `values` and `enum`.
- [x] 2.3 Refuse a non-string `default:` on a `datetime` parameter at load, naming the parameter.
- [x] 2.4 Refuse a **bare** token in any `default:` at load, via `scan_tokens` + `parse` rejecting `Source::Bare`, as a `TemplateError::Validation { path: "default", .. }`, so the quarantine path and the `POST`/`PUT` refusal are covered by one check.
- [x] 2.5 Refuse an unterminated `{` or unmatched `}` in any `default:` at load, naming the parameter, with a validator that scans the default for well-formed tokens and applies the render path's brace-balance rule to the text between them, honouring `{{`/`}}`. Build it on neither of the two obvious candidates: `scan_tokens` skips malformed brace sequences by design (`src/interpolation.rs:178-192`), and `process_literal_chunk` (`src/render/helpers.rs:39-63`) rejects every undoubled `{` because the render path only ever hands it the gaps between tokens (`:86-92`, `:141-143`), so running it over a whole default would reject a valid `{sys.now}`. Share the escape and token handling with the render path rather than reimplementing it, or the two will disagree about which strings are legal.
- [x] 2.6 Extend `templates.rs`'s `validate` to run the remaining token refusals (unknown source, unknown `sys` value, malformed name, a format on something that is not an instant) over `params[*].default`.
- [x] 2.7 In `parse_datetime_in_tz` (`src/datetime_fmt.rs:44-55`), resolve a **date-only** value whose local midnight does not exist to the first instant that does exist on that date, keeping the rejection for a date-and-time value naming a nonexistent local time. Without it, `default: "{sys.now}"` — the migration this change prescribes — fails every render for a whole day each year in any zone transitioning at `00:00`.
- [x] 2.8 Scope the existing default-instantiation checks (`reject_enum_default_not_in_values`, the frame-overflow check) to defaults carrying **no interpolation syntax at all**, not merely no token: `{{draft}}` carries no token yet resolves to `{draft}`, and the enum check compares the raw string against `values` (`src/templates.rs:1256-1274`), so a token-based test refuses a default that resolves to an allowed value and admits one that resolves outside the set. A default carrying any brace is treated at load exactly as no default at all.
