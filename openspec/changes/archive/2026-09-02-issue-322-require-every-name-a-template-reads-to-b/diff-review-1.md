**1. `docs/AUTHORING.md` now teaches two things the service refuses. (blocking)**

`docs/AUTHORING.md:397`: "A field the layout references but `params:` does not declare still takes a `<textarea>` from a wrapping text item that reads it; issue #269 removes that fallback, after which the declaration is the only source." This change removed that fallback — `multiline_text` and the `undeclared_specs` branch are gone from `derive_inputs_internal` (`src/templates.rs:199-207`, `:368-375`). The sentence describes dead behaviour and attributes its removal to work that has not happened.

`docs/AUTHORING.md:609`: "`{datetime}` is an ordinary request data field, not a reserved word." Under the shipped contract `{datetime}` is a bare token that must name a declared parameter; a template printing it without declaring it is quarantined. The change's own test `issue_322_namespaced_tokens_and_defaults_and_datetime` asserts exactly that (`src/templates.rs:7161-7175`), and the `interpolation-tokens` delta restates the scenario "The retired bare spelling becomes an ordinary field" to say so.

AGENTS.md names `AUTHORING.md` as the human-facing "template model by worked example", and it is not frozen. This is a BREAKING change to what an author may write, and the authoring guide tells them the old spelling still works. Fix the two sentences, or file an issue and say so — the plan's Impact section enumerates Code/API/Templates/Tests/UI and never considered docs, which is where this slipped.
