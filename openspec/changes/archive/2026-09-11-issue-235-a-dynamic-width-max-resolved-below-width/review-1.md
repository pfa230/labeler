Thus an inverted pair combined with invalid item geometry can change an existing `422` into `400`. Add an HTTP regression with legal inverted bounds and an authored item width resolving to zero: expect `width_bounds_inverted`; with ordered bounds, expect the existing `size_invalid`. Replace “Not breaking” with an acknowledgment of the error-contract change, consistent with [AGENTS.md:203](/home/pfa/projects/labeler/.worktrees/issue-235/AGENTS.md:203).
