**Blocking findings.**

1. **Load-time refusal of a whitespace-padded colour literal is load-bearing, unguarded and untested.** `color: " red "` is refused at load only because `RawColor::from_str` returns `Err` unconditionally (`src/raw.rs:34-39`), which makes `DynamicValueVisitor::visit_str`'s fast path `if let Ok(val) = trimmed.parse::<T>()` (`src/models.rs:330`) miss and fall through to `RawColor::deserialize`, which keeps the untrimmed `v` (`src/raw.rs:27`). I reproduced both branches in a scratch crate outside the repo [verified by run]: with the shipped `Err`-only `FromStr` the value reaching `convert.rs` is `RawColor(" red ")`, which `Color::from_str` then refuses; with a working `FromStr` it is `RawColor("red")`, which loads and paints red. Nothing in the tree tests the load half. `" red "` and `" #ff0000 "` are asserted only against the parser (`src/models.rs:1418-1419`), and the whitespace test added for round 3's finding covers only the render path (`src/render/mod.rs:8797-8825`). Failure scenario: someone later gives `RawColor` a real `FromStr` (the obvious thing to do with a type whose `from_str` is a stub), every test still passes, and `color: " red "` loads while `brand: " red "` supplied to the same field still fails `color_param_invalid`. That is the load-versus-render divergence `design.md` names under Risks with #150 and #155 as precedent, on the exact input round 3 spent a round on. One load-level case per field (`text.color`, `background`, `stroke.color`) closes it; a comment on `src/raw.rs:37` naming the dependency would help but is not a substitute.

2. **ADR-0093 §1 records the opposite of what was built.** `docs/adr/0093-one-colour-type-and-vocabulary.md:25` says the surviving type holds `{ pub spelling: String, pub rgba: [u8; 4] }`. Both fields are private (`src/models.rs:831-833`), reachable only through `spelling()` and `rgba()` plus a `#[cfg(test)]` `from_rgba`. The privacy is deliberate and was the answer to round 4's finding 5: private fields are what make "one parser, one table" structural rather than conventional, since a caller cannot build a `Color` whose spelling and rgba disagree. AGENTS.md makes ADRs append-only and says to supersede rather than edit, so this is the last cheap moment to correct a clause that tells a future reader direct construction is sanctioned. One word.
